# Tachkila – Composition d'équipe

## Présentation
Tachkila est un projet web qui permet de préparer une composition d'équipe de football.

## Technologies utilisées
- HTML
- CSS
- JavaScript
- Tailwind CSS

## Installation
1. Télécharger ou cloner le projet depuis GitHub.
2. Ouvrir le dossier du projet.
3. Ouvrir le fichier `index.html` dans le navigateur.

## Structure du projet
- `index.html` : structure de la page.
- `style.css` : styles personnalisés.
- `script.js` : fonctionnalités JavaScript.
- `img/` : images utilisées dans le projet.
