# Tachkila — Composition d'équipe

## Présentation

Tachkila est une application web qui permet de gérer une équipe de football et de préparer une composition sur un terrain en formation 4-4-2.

## Fonctionnalités

- Ajouter un joueur avec son nom, son poste et son numéro.
- Modifier et supprimer les informations d'un joueur.
- Afficher les joueurs sur le banc des remplaçants.
- Placer les joueurs sur le terrain selon leur poste.
- Vérifier la validité et l'unicité des numéros.
- Empêcher l'occupation d'une position déjà utilisée.
- Afficher les positions libres et occupées.
- Sauvegarder les données avec LocalStorage.

## Technologies utilisées

- **HTML5 :** structure de la page.
- **CSS3 :** mise en forme de l'interface.
- **JavaScript :** gestion des joueurs et interactions avec le DOM.
- **Tailwind CSS :** stylisation et adaptation de l'interface.

## Installation

1. Cloner le projet depuis GitHub.
2. Ouvrir le dossier du projet dans VS Code.
3. Ouvrir le fichier `index.html` dans un navigateur.

## Structure du projet

- `index.html` : structure de la page.
- `style.css` : styles personnalisés.
- `script.js` : fonctionnalités JavaScript.
- `img/` : images utilisées dans le projet.
